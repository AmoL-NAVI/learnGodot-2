## Day1
### 完成内容
- 玩家场景
- 有限状态机FSM实现的对象状态控制
- 玩家动画
- 生命控制组件-可用于对所有含有生命属性的对象进行生命值控制
### 核心
- FSM实现的对所有对象的状态控制

## Day2
### 完成内容
- 游戏地图场景搭建，包含小镇，湖泊，怪物刷新点
- 实现部分玩家界面
### 核心
- 使用TileMayLayer中地形实现的自动生成地形

## Day3
### 完成内容
- 完成ui界面设计，包含右下角四个功能面板，技能栏和玩家状态显示
### 核心
- 使用HUD节点和各种容器实现的交互页面

## Day4
### 完成内容
- 物品的逻辑架构部分完成-模块置于data文件夹中
- Item基类继承自Resouse，包含道具的共有属性:图片资源，名称，描述...
- 而后创建ItemData类，描述物品的可消耗性，可堆叠性以及类型
- 而后可以为每个不同类型的道具单独创建文件夹，创建各个道具独自的tres文件，再为每个道具直接在检查器中配置属性
- 为了能更好的调试查看仓库中的物品，选择自建新数据类型SlotData记录了ItemData和quantity
- 再建立autoload的数据结构inventory来记录仓库中的物品，采用Array[SlotData]来记录内容并在其中实现了仓库的存储逻辑
- 建立掉落物场景DropItem，采用Area2D来检测与玩家之间的碰撞
### 核心
- 各个模块之间的组织和数据结构的选用
